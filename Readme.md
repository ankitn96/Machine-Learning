# Machine Learning Classification Projects

A collection of machine learning projects demonstrating classification techniques, ensemble learning, model evaluation, and algorithm implementation using Python.

## Overview

This repository contains two end-to-end machine learning projects developed using Python, NumPy, Pandas, Matplotlib, and Scikit-learn.

The projects focus on:

- Supervised Learning
- Classification Models
- Ensemble Learning
- Data Preprocessing
- Hyperparameter Tuning
- Model Evaluation

---

# Project 1: Softmax Regression on MNIST

## Objective

Build a multiclass classifier capable of recognising handwritten digits using Softmax Regression implemented from scratch.

## Dataset

MNIST Handwritten Digits Dataset

- 70,000 images
- 10 digit classes
- 784 features per image

## Techniques Used

- Softmax Regression
- One-Hot Encoding
- Cross Entropy Loss
- Gradient Descent
- Early Stopping
- Train / Validation / Test Splits

## Skills Demonstrated

- Mathematical implementation of machine learning algorithms
- Numerical optimisation
- Classification evaluation
- Model training and validation

# Project 2: Heart Disease Prediction Using Ensemble Learning

## Objective

Predict the presence of heart disease using clinical patient data and compare multiple machine learning approaches.

## Dataset

Cleveland Heart Disease Dataset

Features include:

- Age
- Sex
- Cholesterol
- Blood Pressure
- Maximum Heart Rate
- Chest Pain Type
- Exercise-Induced Angina

## Models Implemented

### Decision Tree

Used as a baseline interpretable model.

### Random Forest

Improved performance through ensemble learning and bagging.

### AdaBoost

Applied boosting techniques to enhance predictive accuracy.

## Evaluation Metrics

- Precision
- Recall
- F1 Score
- Classification Reports

## Skills Demonstrated

- Data Cleaning
- Feature Engineering
- Hyperparameter Tuning
- Ensemble Learning
- Performance Analysis
